# 跨机器路径配置

公开版脚本不再依赖作者电脑的 D 盘路径。默认只使用包内目录、用户目录或系统 `PATH`；需要接入自己的安装位置时，可设置这些环境变量：

| 环境变量 | 用途 |
|---|---|
| `COMFYUI_WORKFLOWS_DIR` | ComfyUI 工作流目录，供批量提示词 GUI 搜索 |
| `DRAGONMAID_WORKSPACE` | 你自己的项目或素材索引目录 |
| `COMFYUI_CUSTOM_NODES` | ComfyUI 的 `custom_nodes` 目录 |
| `QWEN3_TTS_MODEL_DIR` | Qwen3-TTS CustomVoice 模型目录 |
| `DMT_AI_STUDIO` | 可选的一体化工作台根目录；未设置时使用 `~/DMT-AI-Studio` |
| `DRAGONMAID_QWEN_TTS_ENDPOINT` | Qwen TTS 合成接口 |
| `DRAGONMAID_QWEN_TTS_HEALTH` | Qwen TTS 健康检查接口 |
| `FFMPEG_EXE` | `ffmpeg` 可执行文件；默认从系统 `PATH` 查找 |

例：PowerShell 当前窗口临时设置

```powershell
$env:COMFYUI_WORKFLOWS_DIR = 'C:\ComfyUI\user\default\workflows'
$env:QWEN3_TTS_MODEL_DIR = 'E:\AI-Models\Qwen3-TTS-12Hz-1.7B-CustomVoice'
```

不开 TTS 时，无需安装语音依赖；批量提示词 GUI 只需要 Python 标准库和 Tkinter。
