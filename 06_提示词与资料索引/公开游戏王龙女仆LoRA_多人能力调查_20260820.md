# 公开游戏王 / 龙女仆 XL LoRA 多人能力调查（2026-08-20）

> 调查范围：SDXL 1.0、Pony XL、Illustrious XL 系列。优先引用作者模型页、Civitai 模型页及其示例生成参数；没有下载大模型，也没有生成图片。

## 先说结论

1. **小粉 LoRA 能很好地生成小蓝，主要原因不是两人长得像，而是它本来就是联合训练的多概念 LoRA。**公开页明确把 `nurse dragonmaid` 和 `laundry dragonmaid` 列为角色 1、角色 2，并分别列出 `dragonmaid ernus`、`dragonmaid nudyarl` 两种龙形态。
2. Civitai 的作者示例提供了更强证据：Nurse 版的 10 个作者示例中有 8 个带多人词；首个示例只加载一份 Nurse LoRA（约 0.74），却同时提示 `2girls`、`nurse dragonmaid`、`laundry dragonmaid`。这不是外貌碰巧接近能解释的。
3. 这些优秀文件采用的是**多概念联合训练**：每个角色有独立 trigger，数据里既有单人身份图，也有明确标注的 `together / 2girls` 同框图。它和“把两个成品 LoRA 权重硬叠、拼接或求平均”不是一回事。
4. **一个文件能分别触发多个角色，不等于它一定能稳定画出多人同框。**真正可信的多人证据必须是：同一张示例只加载这一份 LoRA，同时出现两个 trigger、`2girls`，并且成图身份分离。现有 Dragonmaid 公开模型里，Nurse＋Laundry 的证据最完整。
5. 外形和画风接近只是次要优势：同系列女仆共用线稿、制服、龙角、尾巴等视觉语汇，联合训练更省容量；但相似也会增加串发色、串服装的风险，并不是成功的根本原因。

## 三种做法必须区分

| 做法 | 文件如何产生 | 优点 | 主要问题 |
|---|---|---|---|
| 推理时硬叠 LoRA | 加载两个独立 LoRA，一起作用于整张图 | 不用训练 | 两套权重争夺同一身体、服饰和颜色；最容易串角色 |
| 成品 LoRA 合并/拼接 | 对现有权重平均、相加或 concat | 一个文件便于管理 | 没学过角色间空间关系；通常不能修复双人构图 |
| 多概念联合训练 | 从训练阶段就放入多个 trigger、单人图和同框图 | 能在同一权重空间里分离概念，并学习同框关系 | 数据标签和配比要求高；角色越多越容易互相污染 |

Sqquirtle0007 的公开 Illustrious 系列属于第三种。对本机已下载文件的元数据复核还显示：

- Nurse：Nurse＋Laundry＋两者龙形态＋`together` 组；206 个训练目录条目（跨目录可能重复），按 repeats 加权约 4710，`rank 16 / alpha 8`。
- Kitchen：Kitchen＋Laundry＋Tinkhec＋`together`。
- Parlor：Parlor＋Laundry＋Lorpar＋`together`。
- Chamber：Chamber＋Latys＋Stern＋`together`。
- House：House＋Sheou。

这组元数据解释了为什么小粉、小蓝组合明显优于我们之前的硬叠实验。

## 这些模型究竟在哪里制作、发布

- 主要发布地是 **Civitai、Tensor.Art、PixAI**。Sqquirtle0007 的多概念系列在 Civitai 有原始模型和作者示例，Tensor.Art 也有作者/重复页面。
- 页面写 `Original` 只能说明平台上的原创发布声明；不代表一定使用该平台在线训练。页面没有披露 Kohya、OneTrainer 或 Tensor 在线训练时，不能反推训练工具。
- 页面写 `Reprint` 时应回到其指向的 Civitai 原始页核对许可。Tensor 的 Kitchen Pony 转载页就明确限制为学习交流、不可商用。
- Hugging Face 的归档仓库可帮助找失效文件，但属于镜像/归档，不应被当成原作者许可来源。

## 推荐复现路线

不要继续做七个成品 LoRA 的权重硬叠。更接近小粉＋小蓝成功方式的是：

1. 先做两个角色的联合训练实验，而不是七人版。
2. 每个角色保留独立 trigger；单人身份图仍占主要比例。
3. 加入少量高质量同框图，caption 必须同时包含 `2girls`、两个角色 trigger，以及明确的左右/前后位置和互动关系。
4. 为 `together` 单独建数据子集，避免普通单人图错误标成多人。
5. 先验证“分别单独触发不串色”，再验证“双 trigger 同框身份分离”。
6. 训练文件可用中低 rank；Nurse 公共文件的本机元数据是 `rank 16 / alpha 8`，说明成功不依赖极高 rank，而更依赖数据组织和 caption。
7. 即使联合训练通过，亲密接触、遮挡严重或三人以上场景仍建议使用姿势/蒙版/区域重绘。

## 最终判断

小粉＋小蓝的效果好，按证据排序是：

1. **同一 LoRA 从训练阶段就包含两个独立角色概念；**
2. **训练数据存在 `together` 组，公开示例又明确用单份 LoRA 生成 2girls 双 trigger；**
3. 两人属于同一画风和同一服装体系，便于共享低层特征；
4. “两个人长得像”只占很小因素，而且过度相似反而会增加串发色和串服装。

因此最值得复制的不是它的文件合并方式，而是它的**联合数据配方与标签结构**。

## 证据等级

- **A**：原始/作者模型页，同时有 trigger、底模、权重和可检查的同框示例参数。
- **B**：模型页明确列出多概念或人形＋龙形，但同框证据不足。
- **C**：仅转载页、搜索摘要或归档文件名；可用于发现，不足以证明能力和许可。
