# 龙女仆 LoRA、底模与叠加关系说明

## 1. 当前主要底模

- ComfyUI 名称：`sdxl\waiIllustriousSDXL_v150.safetensors`
- 架构：SDXL / Illustrious 系二次元模型
- 作用：负责整体画风、光影、构图能力与通用人体知识。

LoRA 不是完整模型。角色 LoRA 主要把角色的头发、角、服装、尾巴和部分训练集画风作为增量叠加到底模上。

## 3. 是否混合了两个 LoRA

### 五级好感 CG 旧任务

旧任务确实加载了两个 LoRA，但不是两个角色 LoRA：

1. 对应角色 LoRA：模型权重 `0.82`，文本编码器权重 `0.76`。
2. `PerfectHands_xiushou_SDXL.safetensors`：模型权重 `0.10`，文本编码器权重 `0.05`。

第二个是低权重手部修复 LoRA。它可能改善部分手部，也可能轻微改变线条、肤质和构图。它不负责角色身份。

### 130 张“去油腻”SFW 预览

这一批只加载了一个角色 LoRA，没有加载 Perfect Hands，也没有混合第二名角色。偏平、偏动画设定稿主要来自正向风格词：

`clean anime visual novel CG, matte skin, soft cel shading, flat controlled highlights, pastel color palette, low saturation, clean lineart`

因此质量下降并不是两个角色 LoRA 串在一起造成的，而是风格约束过强。

## 4. 下一轮推荐配置

### A：恢复旧质感（推荐）

- 角色 LoRA：`0.68–0.76`
- Perfect Hands：先关闭；只有固定种子对照证明有效时再以 `0.05–0.10` 加入
- Steps：30
- CFG：4.7–5.0
- Sampler：`dpmpp_2m_sde`
- Scheduler：`karras`
- 正向风格：`polished anime visual novel CG, clean cel shading, coherent natural colors`
- 反向只保留：`plastic skin, greasy highlights, excessive bloom`

### B：轻量抑制油亮（对照，不作为默认）

保持 A 的全部设置，仅添加：

`natural skin highlights, balanced saturation, soft diffuse key light`

不要再使用 `flat highlights`、`low saturation`、`matte skin` 三项一起强压。

## 5. 兼容与叠加原则

- 一个单人角色默认只加载一个角色 LoRA。
- 风格 LoRA、手部 LoRA、姿势 ControlNet 应分别做固定种子开关对照。
- 不同角色 LoRA 直接叠加会造成发色、服装、角和尾巴互串；多人图应采用区域控制、分人生成后合成或局部重绘。
- LoRA 权重越高，不只角色特征越强，训练集里的卡框、平涂、构图和肤质偏差也会越强。
- 小蓝只进入 SFW 工作流，不生成或训练成人内容。
