# 龙女仆七角色配音：ComfyUI + 批量 GUI

## 两个入口

1. **ComfyUI 配音**：打开 `07_龙女仆配音_Qwen_RVC`，里面有 7 份角色工作流。
2. **批量配音 GUI**：本地浏览器界面（`127.0.0.1:9891`），直接填写中文、日语、英语三份独立文案，或导入 TXT / CSV / JSON / XLSX；可逐条设置角色、语言、情绪、语速、种子和是否经过 RVC。它复用现有 Gradio 环境，不依赖本机已损坏的 Tcl/Tk 组件。

## ComfyUI 节点

节点名：`龙女仆｜三份独立文案配音`

每份角色工作流只需修改一个节点：

- 中文文案、日语文案、英语文案分别填写
- “生成语言”只读取与该语言对应的文案，不再复用一个文本框
- 平静 / 开心 / 害羞 / 生气 / 难过 / 惊讶 / 温柔 / 调皮
- 语速、情绪强度、目标响度和种子
- 是否通过 RVC

Qwen 原声默认开启。RVC 不是必经步骤，只有需要 A/B 对照或保留换声链时再打开。RVC 首次加载可能持续数分钟，不建议对整批台词默认开启。

## GUI 批量导入格式

推荐使用三语宽表；导入后每一行会自动拆成三条队列记录：

```csv
id,角色,情绪,语速,情绪强度,中文文案,日语文案,英语文案,目标文件名,种子,使用RVC
001,小红,害羞,0.98,1.0,我才没有特意等你回来。,あなたを待っていたわけじゃないんだから。,I wasn't waiting for you.,line001.wav,20260825,否
```

仍兼容旧的“一行一种语言”CSV。TXT 按“每个非空行一条台词”导入，并使用 GUI 当前选中的角色、语言、情绪和语速。JSON 支持数组，或 `{ "lines": [...] }`。XLSX 会优先读取 `三语生成表`，其次读取 `短语气配音表`。

H5 需求表会生成 97×3=291 条队列；中文、日语、英语分别进入 `zh`、`ja`、`en` 文件夹，并在 `H5_短语气三语_稳定文件名` 下保留游戏可直接引用的稳定文件名。

短语气批处理会读取“建议时长”，遇到超长或近静音结果时自动换种子；仍略超长时使用短淡出限长。网络服务在分批释放显存时若短暂断开，会自动重连后续跑。`生成清单.csv` 记录尝试次数、时长、RMS、状态和最终路径。

## 输出

默认路径：

`D:\DMT-AI-Studio\projects\dragonmaid-galgame\outputs\voice_comfyui`

自动按 `角色 / 语言 / 情绪` 分类。每个 WAV 附带同名 JSON，记录实际音色、情绪、语速、采样参数、响度和 RVC 状态。

## 约束

- 小蓝保持全年龄角色定位。
- 角色名采用常用中文：管家、小红、小绿、小蓝、小粉、小金、小黑。
- TTS 模型继续运行在独立的 Qwen 环境；ComfyUI 只调用本地服务，避免 Python/CUDA 依赖互相污染。
