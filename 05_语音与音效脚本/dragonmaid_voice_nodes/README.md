# 龙女仆 ComfyUI 配音节点

节点名称：`龙女仆｜三份独立文案配音`

- 角色：管家、小红、小绿、小蓝、小粉、小金、小黑。
- 中文文案、日语文案、英语文案是三个独立输入；“生成语言”只取对应输入，避免把同一段中文误交给日语或英语模式。
- 情绪：平静、开心、害羞、生气、难过、惊讶、温柔、调皮。
- 默认使用 Qwen3-TTS 原声；需要保留 RVC 对照时再打开“使用 RVC”。RVC 首次加载可能持续数分钟，不适合作为默认批处理链。
- 自动保持角色试听包的 Speaker、Top-P、Temperature 和重复惩罚参数。
- 输出自动按 `角色/语言/情绪` 分类，并写入同名 JSON 生成记录。
- 小蓝维持全年龄角色定位。

运行依赖保持隔离：ComfyUI 节点通过 `http://127.0.0.1:9881` 调用 TTS 服务，模型不安装进 ComfyUI 的 Python 环境。
