# 龙女仆 ComfyUI 批量提示词输入器

这是旧版外置“Markdown 批量提示词工具”的 ComfyUI 节点版。它保留核心批处理能力，但不再读取或改写工作流 JSON，也不再通过外置窗口调用本机接口。

## 节点位置

重启 ComfyUI 后，在画布空白处右键：

`添加节点 → DragonMaid → 批量提示词`

可以看到三个节点：

- `龙女仆｜批量提示词输入器（单人）`
- `龙女仆｜批量提示词输入器（2～6人对齐）`
- `龙女仆｜批量提示词预览`

## 单人批量出图

1. 添加“单人”节点，把整份提示词粘贴到 `编号提示词_MD`。
2. 推荐格式：

   ```text
   1. smiling, looking at viewer, hand on table
   2. waving, cheerful smile, walking into the kitchen
   3. reading a book beside the window
   ```

   一条提示词可以占多行。也支持用空行或 `---` 分隔未编号的提示词。
3. `统一开头` 填所有图片共用的质量、画风和角色身份；`统一末尾` 填共同的构图约束、SFW 约束等。
4. 把 `提示词列表` 接到 `CLIP文本编码器` 的 `text`。如果 `text` 还是输入框，请右键该节点，选择“将 text 转换为输入”。
5. 把 `种子列表` 接到 `K采样器` 的 `seed`。如果 seed 还没有插口，同样先右键转成输入。
6. 保留原来的模型、负面提示词、空潜空间、VAE 解码和保存图片连线。点击一次“运行/Queue”，下游会按列表逐条执行。

也可以把 `提示词列表` 接到已经安装的 `龙女仆｜六栏提示词控制台` 的“动作提示词”“表情提示词”等任意一栏；先把目标栏转换为输入插口。

## 数量计算

实际任务数为：

`选中的提示词条数 × 每条重复次数`

- `起始条目=1`：从第一条开始。
- `读取条数_0为全部=0`：一直读取到文档末尾。
- `每条重复次数=3`：每个编号连续执行三次。
- 种子从 `起始种子` 逐任务递增，可直接接 KSampler。

第一次使用建议把 `读取条数_0为全部` 设为 `2`，先确认两张图和保存位置，再改回 `0`。

## 2～6人编号对齐

1. 添加“2～6人对齐”节点，将 `角色数量` 设为实际人数。
2. 分别把角色 A～F 的编号 MD 粘贴到对应输入框；未使用的角色框留空。
3. 每份文档必须能按编号一一配对。连续的 `1～100`、`101～200` 这类同长度偏移序列会自动按顺序统一重排。
4. 将 `角色A提示词`、`角色B提示词` 等分别接到各自的区域/角色 CLIP 文本编码器。
5. 只需连接一份 `种子列表` 到最终 KSampler。节点会让同一任务中的所有角色使用相同任务序号与种子。

多人节点只负责“读取、对齐和输出每名角色的提示词列表”，不会自动创建区域遮罩、LoRA 或 Conditioning Combine；这些仍由工作流原有节点负责。

## 先预览、不生图

把任一 `提示词列表` 接到 `龙女仆｜批量提示词预览`，运行后可在节点/执行结果中查看解析出的文本。插件内附的最小示例工作流只做这项检查，不会加载模型，也不会生成图片。

## 与旧外置工具的区别

- 节点版：所有内容保存在工作流里；一次运行即可让 ComfyUI 原生列表机制逐条处理。
- 旧外置工具：读取工作流 JSON 后，逐个改写并通过本机接口加入队列。
- 节点版不会帮你自动改文件名。`Save Image` 会按 ComfyUI 自带编号保存；需要按原 MD 编号命名时，可再连接支持字符串文件名的保存节点。
- 节点版不包含外置窗口里的查找替换、导出任务包和停止提交按钮；文本批改请在粘贴前完成，队列停止使用 ComfyUI 自己的队列面板。

## 安全与兼容

- 节点不访问网络，不读取任意本地路径，不安装额外依赖。
- 只处理文本、编号和整数种子，不占用显存。
- 插件使用 ComfyUI 的 `OUTPUT_IS_LIST` 原生机制；普通下游节点会按列表逐项运行。
